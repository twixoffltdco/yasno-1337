# Ясно — новости без рекламы
Читалка новостей в духе Дзена, но без рекламы и трекеров. Open source (MIT).
- Собирает RSS (Lenta, РИА, ТАСС, BBC Русская служба, DW), всегда показывает источник и ведёт на оригинал
- «Подборка дня» меняется каждые 24 часа (по МСК), лента обновляется каждые 30 минут
- SEO: серверный рендер, canonical, OpenGraph, JSON-LD NewsArticle, sitemap.xml, robots.txt, rss.xml
- Режимы: «Для старших» (крупный контрастный шрифт), тёмный, кнопки А−/А+; реакции — локально в браузере
- PWA: ставится как приложение, работает офлайн (кэш)

## Запуск
    npm install
    SITE_URL=https://твой-домен.ru npm start      # http://localhost:3000
Свои источники — массив FEEDS в server.js. Node 18+.
